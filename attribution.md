# Data Attribution

## Grateful Dead Setlist Data

The setlist data used in this project was sourced from the **Grateful Dead Setlists** database maintained by Mark Leone at Carnegie Mellon University.

- **Source:** https://www.cs.cmu.edu/~mleone/gdead/setlists.html
- **Coverage:** 1972–1995
- **Original Database:** Created by Jerry Stratton (jerry@teetot.acusd.edu) and others
- **1995 Data Collected & Formatted By:** Tim Buller (tjb9d@bethelks.edu)

This data was scraped for personal, non-commercial use as a tribute to the Grateful Dead and their music. No ownership of this data is claimed.
